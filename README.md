### What I'm building

**[Francaisia →](https://francaisia.com)** — French-learning platform for Canadian immigration

Premium TEF Canada prep for Express Entry candidates targeting CLB 7 / B2. 90+ lessons from A0 to B2, an immersive gamified lesson player, and a fully voiced narrative arc — built on a science-based methodology (spaced repetition, comprehensible input, shadowing).

`Next.js 16` &nbsp;·&nbsp; `Supabase` &nbsp;·&nbsp; `Stripe` &nbsp;·&nbsp; `Vercel`

**[PRAVÉ →](https://pravepath.ca)** — Express Entry CRS optimization tool

A CRS score calculator and draw simulator for Canadian permanent-residency applicants: 400+ historical draws, provincial nominee (PNP) matching across 11 provinces, and an AI-driven strategy engine.

`Next.js 16` &nbsp;·&nbsp; `Supabase` &nbsp;·&nbsp; `Stripe` &nbsp;·&nbsp; `Google OAuth` &nbsp;·&nbsp; `Vercel`
